# ABD WP

A professional blue-and-white WhatsApp-style Android starter app.

Included:
- Phone number login screen
- Demo OTP + PIN flow
- Chats UI
- Group chat placeholder
- Status screen
- Voice/video call placeholders
- Profile + banner
- Permissions in AndroidManifest
- Blue/white professional theme

Important:
The OTP, real messaging, media upload, online presence, status sync, and voice/video calls are UI/backend-ready placeholders. To make them real, connect a secure backend such as Firebase Authentication/Firestore/Storage and a WebRTC-based calling service.
